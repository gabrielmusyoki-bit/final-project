# Gabriel Musyoki — Personal Portfolio

A modern, responsive personal portfolio website showcasing Gabriel Musyoki's interests, goals, and projects. Built as a class final project to demonstrate HTML, CSS, and web design fundamentals.

## Overview

This is a multi-page portfolio site that presents Gabriel's journey balancing his passion for football with engineering aspirations, along with hobbies and current projects. The site features a clean, minimalist dark theme with intuitive navigation.

## Features

- **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
- **Multi-page Navigation** — Three main pages (Home, About, Projects) with smooth navigation
- **Modern Styling** — Dark theme with custom typography using Google Fonts (Oswald & Roboto)
- **Accessibility** — Semantic HTML with ARIA labels for better screen reader support
- **Clean Layout** — Card-based design for organized content presentation
- **Personal Brand** — Logo mark (GM) and consistent branding throughout

## Pages

### Home (`index.html`)

- Hero section with personal introduction

## How to View

1. Open any HTML file in your web browser
2. Start with `index.html` for the best entry point
3. Use the navigation menu to explore other pages

## Setup & Running Locally

No build process or dependencies required — simply open the HTML files directly in your browser or serve them using a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if installed)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.
